# MoYu Reader v1.0.0

Windows 10 / 11 x64 免安装版。无需安装 Python 或额外运行依赖。

## 下载与使用

下载 **MoYuReader-v1.0.0-Windows-x64.zip**，完整解压，双击 **MoYuReader.exe**。请保留 `_internal` 文件夹，不要直接在压缩软件内部启动。GitHub 自动生成的 Source code 是开发源码，不是 EXE 安装包。

书库、设置、下载文件保存到 `%LOCALAPPDATA%\MoYuReader`。书库底部可直接打开数据目录；更新程序文件不会覆盖用户数据。关闭书库后程序保留在托盘，右键托盘选择“退出 / Quit”可完全关闭。

## 本版功能

- 重新设计书库和下载界面：浅色配色、清晰的主次操作、书名搜索、空状态、设置数值和实时预览。
- 启动直接显示书库；右侧设置和下载表单支持滚动，适应较小窗口。
- 深色置顶阅读窗口、透明阅读模式、可调整窗口大小和自动进度保存。
- 修复手动选章被旧进度覆盖的问题，支持长篇文本延迟布局后的定位。
- 通用 HTML / JSON / TXT 小说下载、目录与正文分页、可选 CSS 规则、限速重试和缓存续传。
- 独立用户数据目录、程序图标、启动错误日志、使用说明和第三方组件许可证。
