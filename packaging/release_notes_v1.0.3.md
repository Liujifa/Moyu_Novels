# MoYu Reader v1.0.3

修复详情页只识别最新几章、目录分页未跟随，以及 HTTP 429 后短暂重试又触发限流的问题。Windows 10 / 11 x64 免安装版。

## 下载与续传

- 新增「慢速稳定」选项：单路运行，本站请求至少间隔 6 秒。
- 自动模式默认请求间隔提高到 1 秒，限流后全部本站请求共享更长冷却，默认从 60 秒开始递增。
- 正确读取 `Retry-After` 秒数和 HTTP 日期，不截断服务端要求的长等待；状态栏显示等待倒计时，支持取消。
- 限流后单路续传，保持降速；按站点保存速度和剩余冷却，重启软件后继续遵守。
- 持续限流达到探测上限时停止本次任务，保留章节缓存，不逐章反复重试。

## 目录修复

- 优先跟随「全部目录／全部章节」，按行级章节标记提取链接，避免将作者、分类和最新几章当作整本目录。
- 支持目录首页与后续分页使用不同路径的情况，保留书籍 ID，防止串书。
- 补充移动目录范围分页及重复章节地址回溯校验。

## 验证范围

- 165 项离线测试通过，包含虚拟时钟下的降速、GET/POST 共享冷却、取消及重启续传策略。
- washai 样本目录共 21 页、2040 个不同章节链接，与页面声明数量一致。正文限速验证范围见随包 `docs/pagination-verification.md`；不声称已经下载完整本书。
- 新版「慢速稳定」连续实测另 45 章，45 次请求全部 HTTP 200，未出现 429，耗时约 265 秒。此前 4 秒起步的 45 章探测出现过一次 429，因此保守模式改为至少 6 秒间隔。
- 发布包自检验证界面、章节跳转、本地动态目录、正文分页和索引保存。

## 使用

完整解压 `MoYuReader-v1.0.3-Windows-x64.zip`，双击 `MoYuReader.exe`，保留 `_internal` 文件夹，无需 Python。

退出旧版后换用新版。书库、缓存和设置仍在 `%LOCALAPPDATA%\MoYuReader`，源码运行的数据仍在项目目录，两个目录不会自动合并。遇到本站限流可选择「慢速稳定」，重复输入同一地址会复用已完成章节缓存。站点仍可能实施更严格的请求限制，软件会等待或停止并保留缓存。

校验文件和第三方许可证随发布提供。
